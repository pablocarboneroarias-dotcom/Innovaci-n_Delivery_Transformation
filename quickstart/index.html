          Governance & The 5 Quality Gates

          Grounded in the EBOAP Constitution v1.3.0, every delivery item must satisfy rigorous quality gates and human authorization before promotion.

          Run Well-Architected Audit →
          Quality Gate 1

          Static Analysis Gate

          Salesforce Code Analyzer scans must be clean of Critical & High severity violations (PMD, ESLint, SFGE).

          Quality Gate 2

          Coverage & Assertions Gate

          Automated unit test suites must achieve ≥85% code coverage on Apex with bulk verification (200+ records) and Jest LWC tests.

          Quality Gate 3

          Sandbox Environment Gate

          Metadata must deploy and validate with zero errors in dedicated sandboxes before release branch merge.

          Quality Gate 4 & 5

          Playwright E2E & Release Gate

          Automated browser user journeys validate acceptance criteria; release checklist verifies i18n (EN/SV), Nebula Logger, and human sign-off.
