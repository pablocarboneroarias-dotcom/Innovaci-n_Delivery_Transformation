Getting Started with the Cadence AI Workspace

This comprehensive guide walks you through setting up your environment, configuring MCP servers, validating tools, and launching your first skills in VS Code Copilot Chat.

Automated Environment Diagnostics

Copilot can scan your development machine end-to-end: verifies Git, Node, Salesforce CLI, Code Analyzer plugins, MCP servers, and source tracking with one click.

Run /platform-environment-validate in VS Code

What you get in this AI delivery workspace

  • Spec Kit SDD Engine: Full lifecycle commands (/speckit.constitution, /speckit.specify, /speckit.clarify, /speckit.plan, /speckit.tasks, /speckit.analyze, /speckit.implement).
  • 98 Specialized Skills: Covering Apex (≥85% test coverage), LWC with SLDS 2 styling hooks, Flow automation, Named Credentials, and Playwright E2E testing.
  • MCP Ecosystem: Pre-configured sf-mcp-server (@salesforce/mcp) and Figma MCP (com.figma.mcp/mcp) inside .vscode/mcp.json.
  • Nebula Logger Mandatory Observability: Standardized structured logging across Apex, LWC, and Flow.
  • Automated 5 Quality Gates: Code Analyzer static scan, Coverage Gate, Sandbox Deploy Gate, E2E Gate, and Release Verification Gate.

Step 1: Install Tools & Extensions

In Windows PowerShell or macOS Terminal, install the prerequisites:

# Install Salesforce CLI
npm install -g @salesforce/cli

# Verify versions
git --version
node --version
sf --version

Step 2: Verify MCP Configuration

Cadence comes pre-configured with .vscode/mcp.json. When you open Copilot Chat, it will automatically connect to:

  • Salesforce MCP Server: Provides DevOps Center tools, Apex unit tests, SOQL execution, and metadata deployments.
  • Figma MCP Server: Provides design-to-code inspection, Code Connect mapping, and design context extraction.

Step 3: Validate Your Development Environment

Launch the automated environment validation skill to verify all CLI plugins, Node modules, and source tracking:

Run Environment Diagnostic

Executes a full prerequisite scan showing 🔴/🟡/🟢 status for all required tools and suggests one-click repairs.

Run /platform-environment-validate in Copilot
